# PixCake Preview Creative Workflow

一个面向 Codex 的像素蛋糕（PixCake）人像修图前置工作流。

它让 Codex 先读取并分类当前本机/账号实际可用的 PixCake 预设，根据照片内容选择候选预设，在像素蛋糕中检查真实处理预览，再把干净原片与已完成的预览分别作为事实来源和人像精修参考，用于后续独立二次创作。

> 本项目是社区工作流，不是 PixCake 官方项目。使用前需要已经安装、登录并获得 PixCake MCP 的正常使用权限。

## 解决什么问题

直接进行 AI 二创时，人脸磨皮、眼周处理、妆容保留和轻微轮廓优化往往不稳定；只凭预设名称选择，也无法判断真实的磨皮强度和偏色情况。

本 Skill 将两类任务拆开：

- PixCake 负责真实的人像精修判断与预览；
- 二次创作工具负责版式、氛围、插画、海报或其他创意表达。

干净原片始终是身份、姿态、服装、手部、场景和照片像素的唯一事实来源。PixCake 预览只提供肤质、眼周、妆容、面部亮度和局部对比参考。

## 完整流程

```mermaid
flowchart LR
    A[选择原片] --> B[读取当前 PixCake 预设]
    B --> C[分类、去重并建立候选]
    C --> D[代表照片试片]
    D --> E{预览是否自然}
    E -- 否 --> C
    E -- 是 --> F[通过 MCP 应用预设]
    F --> G[在 PixCake 中检查完成预览]
    G --> H[截取预览作为精修参考]
    H --> I[干净原片 + 预览 + 可选风格参考]
    I --> J[生成独立二创成片]
    J --> K[保存成片与映射清单]
```

### 1. 选择照片

- 对连拍和近似画面先分组；
- 优先选择眼神清楚、表情自然、手部完整、有情绪和叙事价值的画面；
- 排除闭眼、过渡表情、失焦、遮挡严重和没有新增信息的重复帧；
- 默认保持原片横竖方向，用户明确指定时以用户要求为准。

### 2. 实时读取并分类预设

每个新任务都从 PixCake MCP 重新读取当前预设，不在 Skill 中固化某台电脑的预设名称或 ID。

分类至少覆盖：

- 基础肤质与肤色；
- 婚礼、婚纱与情侣；
- 儿童、新生儿、孕妇与家庭；
- 证件、职业和多人合照；
- 胶片、相机模拟与复古；
- 电影、情绪、暗调与夜景；
- 古风、新中式与民族；
- 清新、日系、韩系与自然；
- 油画、艺术与梦幻；
- 旅拍、季节、花景与户外；
- COS、二次元和特殊主题；
- 通用写真、肖像与其他。

名称末尾带有 `（1）`、`（2）` 等复制编号的预设会作为同一预设家族浏览，但每个真实 ID 都会保留，应用时不会混用。

### 3. 根据照片建立候选列表

候选选择同时考虑：

- 人物：新娘、新郎、情侣、多人、儿童或长辈；
- 景别：面部特写、半身、全身或环境人像；
- 光线：自然光、逆光、混合光、弱光或高反差；
- 精修需求：瑕疵、眼周、肤质、妆容和轮廓；
- 色彩要求：保留原色、纠正偏色或采用明确风格；
- 风险：塑料皮、过度瘦脸、过度美白、背景偏色和多人处理不一致。

预设名称只用于判断方向，不能证明真实效果。磨皮强度、脸型变化和颜色漂移必须在实际预览中验证。

### 4. 代表照片试片

大型预设库不需要逐个盲测。优先从相关分类中选择少量代表候选，再用以下标准照片进行对比：

- 一张近距离人像；
- 一张环境人像；
- 一张多人或男女同框照片。

如果皮肤变得塑料、身份变化、妆容丢失、头发或面纱边缘异常，或者现场颜色明显漂移，则换用更温和的候选预设。

### 5. MCP 应用与预览检查

- 创建或复用一个 MCP 可见的 PixCake 项目；
- 记录 `image_id` 与原始文件名的精确对应关系；
- 使用真实 `preset_suit_id` 应用预设；
- 检查成功、失败、跳过和无变化数量；
- 在 PixCake 主程序中打开准确文件，等待人像处理完成；
- 必要时与原图对照，检查人物身份、肤质、眼睛、嘴唇、发际线、手部、面纱、首饰和场景颜色。

如果 MCP 提示 PixCake 不在主页，应先回到“我的主页”再重试。

### 6. 获取预览参考

处理完成后截取 PixCake 当前画面，并尽量裁掉菜单、滑杆、缩略图和其他界面元素。

预览中可能包含 PixCake 水印。它只能作为肤质和人像处理参考，不能被当作干净成片，也不能直接生成一个去除付费预览水印的替代文件。

### 7. 二次创作的输入职责

| 输入 | 职责 |
|---|---|
| 干净原片 | 身份、姿态、手部、服装、几何关系、场景细节和干净像素 |
| PixCake 完成预览 | 肤质、瑕疵清理、眼周、妆容、面部亮度、局部对比和色彩响应 |
| 可选风格参考 | 版式、材质、视觉系统或艺术方向 |

生成指令必须明确这些职责，并禁止复制预览中的水印、界面、图标和其他覆盖元素。

### 8. 保存和报告

- 生成新的版本化成片，不覆盖原片；
- 记录原片、预设名称、预设 ID、预览参考和最终成片的映射；
- 默认不调用 PixCake 导出；
- 只有用户明确要求导出并理解可能产生费用时，才可以执行导出。

## 使用前提

- Codex 能够加载本仓库中的 Skill；
- PixCake 主程序已经安装、登录并保持运行；
- PixCake MCP 已正确连接且账号具备使用权限；
- 需要二次创作时，环境中还应具备相应的图像生成或图像编辑能力。

## 安装

推荐直接让 Codex 的 `$skill-installer` 从本 GitHub 仓库安装：

```text
用 $skill-installer 安装 https://github.com/thjyy/pixcake-preview-creative-workflow
```

也可以手动将本仓库克隆到 Codex 的用户 Skill 目录，使 `SKILL.md` 位于该 Skill 文件夹根目录。官方文档列出的个人目录是 `$HOME/.agents/skills`。

Windows 示例：

```powershell
git clone https://github.com/thjyy/pixcake-preview-creative-workflow.git "$env:USERPROFILE\.agents\skills\pixcake-preview-creative-workflow"
```

安装后的主要结构：

```text
pixcake-preview-creative-workflow/
├── SKILL.md
└── agents/
    └── openai.yaml
```

如果 Codex 没有立即发现新 Skill，请重新打开或刷新 Codex 后再检查。

安装和 Skill 目录规则可参考 [OpenAI 官方 Build skills 文档](https://developers.openai.com/codex/skills)。

## 调用示例

```text
用 $pixcake-preview-creative-workflow 帮我挑这批婚礼照片，先分类本机预设，试出合适的人像效果，再用完成预览进行横版二创。
```

```text
拿像素蛋糕修图。不要导出，先看当前账号的预设并分类，给新郎、新娘和双人照分别选择候选预设。
```

```text
把这组连拍先选片，在 PixCake 里试片，确认肤质和脸型自然后，再把干净原图和预览交给海报 Skill。
```

## 重要边界

- 不绕过 PixCake 的账号授权、MCP 权限或付费机制；
- 不在本 Skill 中保存用户的完整预设库存；
- 不把预设名称当作视觉效果的最终证据；
- 不在未检查真实预览时声称已经使用 PixCake 修图；
- 不把带水印的预览直接处理成无水印成片；
- 不在没有用户明确授权时调用 PixCake 导出；
- 不覆盖或修改原始照片。
